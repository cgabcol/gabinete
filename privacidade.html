Política de Privacidade

Última atualização: 20 de outubro de 2026

Resumo: o Gabinete não coleta, não transmite e não compartilha dados pessoais. Todas as informações cadastradas ficam armazenadas exclusivamente no navegador do próprio usuário.

1. Quem somos

O Gabinete | Painel de Gestão é uma extensão para o Google Chrome que oferece um painel local para organizar links, notas, avisos, processos, contatos, tutoriais, membros do conselho e portarias de uso administrativo.

2. Quais dados são tratados

A extensão permite que o usuário cadastre, por iniciativa própria, conteúdos como:

  • Links e suas categorias;
  • Notas e anotações;
  • Avisos com data e horário;
  • Processos, situações e setores responsáveis;
  • Contatos (nome, telefone, e-mail, cargo e setor);
  • Tutoriais e procedimentos;
  • Membros do conselho, portarias e datas de vigência.

Esses dados são inseridos manualmente pelo usuário e permanecem apenas no navegador em que a extensão está instalada.

3. Onde os dados ficam armazenados

Os dados são gravados localmente por meio de:

  • localStorage — para os registros do painel;
  • chrome.storage.local — para sincronizar a lista de avisos com o agendador de notificações.

Não há servidor próprio, banco de dados remoto, conta de usuário ou sincronização em nuvem. Nenhum dado sai do dispositivo do usuário.

4. Notificações

A extensão pode exibir notificações locais de lembrete para avisos que o próprio usuário cadastrou e marcou com a opção “Ativar notificação”. Essas notificações são geradas pelo navegador, não contêm dados coletados e não são enviadas a terceiros.

5. Compartilhamento com terceiros

Não compartilhamos, vendemos, alugamos ou transferimos dados de usuários a terceiros. A extensão não utiliza serviços de análise, rastreamento, publicidade ou telemetria.

6. Permissões solicitadas e por quê

  • notifications — para exibir lembretes locais dos avisos cadastrados;
  • alarms — para agendar a verificação dos avisos no horário definido;
  • storage — para guardar os registros localmente e sincronizar os avisos com o agendador.

Nenhuma dessas permissões é usada para coletar ou transmitir dados.

7. Backup e restauração

O usuário pode exportar seus próprios dados em arquivo JSON e restaurá-los quando quiser. O arquivo é gerado localmente e salvo no computador do próprio usuário; a extensão não recebe nem armazena esse arquivo em servidores.

8. Segurança

Como os dados permanecem apenas no navegador, a segurança depende das proteções do próprio dispositivo e do perfil do Chrome. Recomendamos manter o navegador atualizado e fazer backups regulares pela própria função de exportação.

9. Direitos do usuário

O usuário tem controle total sobre os dados: pode editar, excluir registros individualmente ou apagar todos os dados locais pela opção “Apagar todos os dados” na página de Backup. Também pode desinstalar a extensão, o que remove os dados associados do navegador.

10. Alterações nesta política

Esta política pode ser atualizada para refletir mudanças na extensão. A data da última atualização será sempre indicada no topo desta página.
